# Changelog

All notable changes to <code>syspeek</code> are documented here. The project follows a
versioned-release model, with the JSON schema version tracked separately from the package version.

## [Unreleased]

### Added

- Initial cross-platform system snapshot command.
- Focused system, CPU, memory, disk, network, and process commands.
- Read-only process metrics with deterministic sorting and limits.
- Human-readable terminal output, stable JSON output, and interactive watch mode.
- Windows, Linux, and macOS CI coverage.
- Architecture, security, contribution, and platform behavior documentation.

Future entries should describe user-visible changes and link to the corresponding release or
comparison when a public release exists.
